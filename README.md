# 竹编器型与编法设计系统

面向竹编工坊的浏览器内设计工具:客户拿照片来要"同款大一号"时,直接改口径,系统按编法规则
重算篾片根数与间距,并在三维模型上检查穿模、急弯、六角孔失真,最后生成按根计算的备料单。
数据全部存在本机浏览器 IndexedDB,不上传服务器。

技术栈:React 19 + TypeScript + Vite + three.js + zustand。

## 启动

```bash
npm install
npm run dev        # 开发,默认 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建
npm run test:geometry   # 无头几何验证(穿模/性能/缩放/备料)
```

## 五个页面

| 页面 | 功能 |
| --- | --- |
| 器型 | 口径/腹径/底径/高度直输;超椭圆截面指数沿高度渐变,支持方底圆口;变截面控制点可增删;子午轮廓实时预览;0.8~1.5 倍快速缩放 |
| 编法 | 十字编、人字编、六角孔编、菊花底;挑压规律用格子图编辑(1=挑、0=压),保存后立即作用到三维;六角孔径可调 |
| 篾料 | 青篾/黄篾、真实宽厚、上漆/烟熏碳化;竹种最小弯曲半径系数与节距;最小弯曲半径随篾厚联动 |
| 三维预览 | 实时编织几何、逆光漏光(六角孔光斑投桌面)、卷口/包边/插口收口、失真黄点与急弯红标、逐圈编织回放 |
| 备料单 | 按根列长宽厚与数量(含损耗下料长),按竹种节距与竹径算一根竹子出几根、本单需几根 |

## 几何引擎如何保证不穿模(核心)

代码在 `src/geometry/`,关键设计:

1. **器型曲面**(`surface.ts`):超椭圆回转体,以 (u,t) 参数化,预计算 96×120 规则网格,
   热路径全部走网格双线性插值,无二分/三角函数,这是两秒内重建的基础。
2. **三种篾片路径**(`weave.ts`):
   - 经篾走**等角子午线**(固定 u),纬篾走**等高圈**(固定 t),斜篾走展开平面再贴曲面。
     等角子午线保证周长收窄时经篾永不重叠——这是早期版本穿模的根因。
   - 六角孔编为三向 60°  kagome 布局,族间错位半间距消除三重交点,交叉成对出现。
3. **挑压抬升**(`ribbon.ts` 的 `stepWaveLift`):每个交叉点对两篾写入相反的 ±篾厚/2 抬升,
   相邻交叉间余弦平滑过渡。交叉点处两篾中心距严格等于一个篾厚,表面相切、数学上不相交。
4. **结构性验证**:每个交叉带 `pairId`,构建后校验每对恰为两篾且 over 相反;
   `npm run test:geometry` 报告冲突数,当前四种编法均为 0 冲突。
5. **弯曲检查**:用不含抬升的曲面路径(贴合器型的真实弯曲),7 点平滑 + 连续两点确认,
   小于竹种系数×篾厚的段标红,避免把挑压起伏误判成折弯。
6. **六角孔保真**:沿高度采样三向间距比,超过 8% 偏差的位置在模型上放黄色标记球。

实测(40cm 六角孔果篮,约 1200 个交叉点):完整重建 **10~30ms**,远低于 2 秒目标;
口径 200/400/600mm 缩放时篾数 62/115/167 随周长自动重算。

## 数据与局限

- IndexedDB 五个对象仓:profiles / patterns / materials / species / designs,首次打开写入种子数据。
- 弯曲半径系数、出材率是工艺经验值,可在篾料页按本坊竹种校准。
- 当前平底盖为平面放射+同心圈;器型为回转体,非回转的异形篮(如椭圆偏心)未覆盖。
