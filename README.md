# 竹编器型与编法设计系统

浏览器本地运行的 React + TypeScript + Three.js 应用。器型、编法、篾料和当前项目均保存在 IndexedDB，不需要后端。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

几何引擎自检（40cm 六角孔果篮的交叉数、生成耗时、穿模间隙、弯曲半径）：

```bash
npm run check:engine
```

## 页面

- **器型**：口径、腹径、底径、高度直接输入；SVG 轮廓点可拖动；超椭圆截面从正圆连续过渡到方截面，可做方底圆口。
- **编法**：十字编、人字编、六角孔编、菊花底起底；可编辑循环挑压格子，点击/拖动批量修改。
- **篾料**：青篾/黄篾、真实宽厚、竹种、清漆/红漆/烟熏/碳化表面；按竹种系数和厚度计算最小弯曲半径。
- **三维预览**：实体带状篾片、交叉上下让位、弯曲超限标红、六角畸变标记、口沿结构、逆光阴影漏光、编织步骤回放。
- **备料单**：按根列出净长和含损耗落料长度，分组计算数量、每竿竹可出根数、所需竹竿数，支持 CSV 导出和打印。

## 几何实现要点

1. `src/lib/shape.ts` 将器型轮廓采样为母线弧长 `s`，截面使用超椭圆参数；按真实截面周长而不是固定角度均布篾片。
2. `src/lib/ribbon.ts` 为每根篾生成带宽度、厚度、UV 和顶点色的四边形截面带状 BufferGeometry。
3. 每个交叉点根据交叉角计算对方篾宽在本篾中心线上的投影；交叉之间使用余弦柔性过渡。中心距至少为一个篾厚加 `0.09cm` 总间隙。
4. `src/lib/engine.ts` 会在每个交叉的完整矩形重叠区内做 7×7 法向偏移采样，输出最小额外间隙，而不是只检查交叉中心点。
5. 六角编使用三向格线。种子根数按参考周长整数化，再反算有效间距，避免圆周取整后水平圈和斜向交叉相位漂移。局部映射后角度/尺度无法保持时输出橙色畸变标记。
6. 弯曲半径由相邻三个截面中心的 Menger 曲率计算；小于竹种允许半径的区段写入红色顶点色并统计长度。
7. 口沿在 `src/three/rimBuilder.ts` 单独建模：卷口圆芯与螺旋锁扎、内外包边带、插口宽篾和短插片。

## 数据

IndexedDB 数据库名：`bamboo-weave-studio`。

对象仓库：

- `shapes`：器型
- `weaves`：编法和格子图
- `materials`：篾料
- `project`：当前项目选择、口沿、损耗、竹竿长度和预览开关

首次打开会写入 40cm 六角孔果篮、方底圆口茶席筐、四种编法和默认篾料。

## 目录

```text
src/
  db.ts                 Dexie/IndexedDB 与初始数据
  types.ts              领域类型
  lib/
    shape.ts            回转/变截面曲面
    ribbon.ts           带状篾片几何与交叉让位
    engine.ts           四类编法生成、交叉和校验
    bom.ts              备料单/竹竿出材计算
    defaults.ts         默认器型、编法、竹种
    material3d.ts       程序化竹纹和材质
  three/
    BasketViewer.tsx    Three.js 场景、阴影、回放显隐
    rimBuilder.ts       口沿结构
  pages/                五个主页面
scripts/check-engine.ts 几何性能/间隙自检
```

## 工艺参数说明

竹种最小弯曲半径系数和修节预留值是可调整的工艺参考默认值，不是不可变的材料学常数。实际使用时可在“篾料”页覆盖最小弯曲半径，并在“备料单”页调整损耗率和可用竹竿长度。
